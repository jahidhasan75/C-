# C Basic Practice — 4 Programs

Beginner-friendly C programs:
1. Hello World
2. Sum of Two Numbers
3. Even or Odd
4. Multiplication Table

## Compile and run (GCC)
```bash
gcc 01-HelloWorld.c -o hello
./hello
```
On Windows:
```bash
gcc 01-HelloWorld.c -o hello.exe
hello.exe
```
Replace the source filename and output name to run another program.
